## Review independence

T01 and T02 are classified `review:required` because they change verifier/authority semantics. The Builder context that implemented them does not publish an Independent Review PASS for its own work.

A required Review remains pending until another independent context reconstructs the facts from GitHub and reviews the exact PR head.

T03 is `review:recommended` because it is a documentation/protocol clarification without changing Validation or Release Authority. A skip decision may be recorded with rationale if exact-head CI/semantic verification passes.

## Validation

Repository Minimal CI remains the executable independent clean-checkout verifier. For v3.2, machine-schema regression is added to the standard verifier workflow by T02.

Any CI result is exact-head evidence for the CI profile only. It does not substitute for required Independent Review or version-level release closeout.
