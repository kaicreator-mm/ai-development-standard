## Existing normative decisions reused, not redesigned

- v5 `ads/github/v5:report` is a strict *shape* contract, not evidence that declared `source_receipt_ref`, `window_current`, provider alias, clock, invoice or publisher namespace is genuine. External owner and native readback must qualify each witness separately before passing rows to this reducer.
- A GitHub public report revision/digest is **not** a physical Attempt ID, metric event ID or accounting receipt. Deduplicate only byte/semantically **whole-record-equivalent** source observations under original identity+revision; same identity/revision/digest/value but different kind/watermark/settlement/aggregation/supersedes is also `CONFLICT`, independent of delivery order. A digest or a caller's `source_current=true` is a claim until qualified by the external evidence owner. Distinct Task/Attempt/provider/adapter/physical retry keys must not collide because their local indices match.
- Group measurement by publisher + Task + Attempt + adapter + provider run + physical attempt, versioned metric/registry/unit, qualified window and original observation ID. Do not add transport duplicates, late revisions, included cache/reasoning subsets, parent/child scopes or mixed delta/cumulative events. Source-only `COUNTER_DELTA` adds only observations with source-attested **mutually disjoint accounting coverage**, represented by a *shared* scoped `delta_nonoverlap_witness` and `delta_nonoverlap_verified=true` for two or more deltas within one physical+metric+window group. This check is a **data-precondition marker**, not an authentication mechanism; two distinct observation IDs alone do not establish disjoint coverage. A missing/contradictory marker yields `UNKNOWN`. All observations require explicit `aggregation_role=LEAF`, never a default LEAF. Source revision histories require root revision 1 and each complete direct predecessor; orphan/gapped histories yield UNKNOWN. Source-only `COUNTER_DELTA` adds nonoverlapping named observations; `CUMULATIVE_SNAPSHOT` chooses the latest witnessed monotone watermark and rejects changed/wrongly ordered source. `UNKNOWN` is not zero.
- Billing identity excludes GitHub Report revision: publisher/economic scope/provider receipt/currency/category/window plus its **source** revision/lineage. A verified **settled** bill may displace a quote/estimate in the *same* scoped population; multiple overlapping bills without reconciliation, missing settlement, disjoint coverage, cross-currency conversion or incomplete invoices remain `UNKNOWN/NOT_COMPARABLE`. Only an actual owner can certify disjoint scopes/settlement. If multiple accounting scopes exist, all scoped rows require a single shared source-qualified coverage witness; independent local witness strings do not prove mutual exclusion. The script expects source-qualified evidence **already verified outside the reducer**; it cannot validate fake self-assertions.
- Time union requires one source-qualified **single publisher/Task/Attempt population** and provably common clock domain and witness; source `window_id` is an opaque lookup key, not endpoints. Never total wall time from different clocks or add overlapping parent spans.
- Positive cases in `tests/fixtures/v416/t02/scenarios.json` are **synthetic** source-contract examples. `scripts/v416_measurement_reconciler.py` has no native GitHub reader and no provider network. It must not be imported as a production accounting control without external source qualification and replay/pagination/privacy proofs. T03 owns the full GitHub public verifier and v3/v4/v5 dispatch.
