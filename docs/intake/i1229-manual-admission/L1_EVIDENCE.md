2. **Optional record fields are not mandatory runtime infrastructure.** §11.1.1 says admission mode/key/generation recording is SHOULD when supported and preserves historical v2 events when those optional audit details were absent. This removes that proposed universal demonstration prerequisite; it does not satisfy an actual engineering predicate. Required epistemic limitation labels remain.

Only actually required resource bindings are obligations (§27.3); no speculative universal resource service is introduced.
