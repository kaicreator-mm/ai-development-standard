# Definition of Done

- risky destructive rewrite/unrelated churn/hidden scope widening/generated-source misuse are deterministically reviewable as implementation-quality defects when material.
- quality standard remains language-neutral and evidence-first.
- no mandatory human line-by-line review gate is introduced.
- automated checks/tests are not described as Release authority.
- Task decomposition and shared-code compatibility owners are not duplicated.
- focused positive/negative evidence is green on exact candidate.
- concern Validation PASS + required Fresh Independent Review PASS bind unchanged candidate.
- merge target is `version/v4.10.0`; Task/PR PASS is not Release PASS.
- proportional Task Learning closeout is recorded.
