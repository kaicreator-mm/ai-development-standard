# V410-T04B Definition of Done

- Accepted Builder claim precedes first source mutation.
- Integrated T04A/T02B semantics are consumed, not redefined.
- Material Review findings are deterministically reconstructible with stable identity, severity, root-defect class and evidence/provenance reference where needed.
- Current aggregation uses only accepted Review facts for the live exact subject; stale evidence remains historical.
- Conflicting/ambiguous current facts fail closed; model/reviewer count, provider brand, cost, speed or file count cannot create authority.
- Root-defect classes bind to T04A repair-routing vocabulary; no second repair lifecycle.
- Historical event payloads remain backward compatible where schema changes occur.
- No new Review event/state/lifecycle/registry or Validation/Release authority.
- Focused + relevant regression suites pass on one exact candidate HEAD/tree.
- Exact-candidate concern Validation + Fresh Independent Review remain independent merge prerequisites.
- Task/PR PASS is not Release PASS.
