# Definition of Done
Either:
A) `NO_CHANGE_REQUIRED`: durable exact-owner evidence proves all Task Pack invariants are already satisfied, identifies what was checked, and records Validation/Review as NOT_APPLICABLE only where the Task Pack permits; no empty PR; or
B) material residual-gap change: smallest existing-owner mutation + focused tests + exact concern Validation PASS + required Fresh Independent Review PASS.

In both paths: no new component registry/DRY authority, no broad refactor, no silent compatibility widening, no Release PASS claim.
