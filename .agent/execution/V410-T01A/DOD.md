# Definition of Done

- Canonical Stage-1 sequence is explicit and matches Frozen Product/L2.
- Product Research remains `as needed`; L1 is not collapsed into mandatory research.
- Product Review selection is proportional/risk-policy driven; Review PASS cannot itself freeze Product.
- low-risk/compact/Fast Path remains legal where higher authority permits.
- Architecture Research is not pulled into Product discovery.
- no second workflow/state/authority family is introduced.
- focused positive and negative regression evidence is green on exact candidate SHA.
- concern Validation PASS exists on exact candidate.
- required Fresh Independent Review PASS exists on the same candidate.
- PR merges only to `version/v4.10.0`; merge does not imply Release PASS.
- Task Learning closeout is `NONE_MATERIAL` or evidence-bound per existing owner.
