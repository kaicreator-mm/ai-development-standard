# Definition of Done

- delegated subwork and responsibility handoff are unambiguous and non-duplicative.
- authority attenuation is explicit; capability/credentials/tool access cannot escalate authority.
- material responsibility/causation can be reconstructed.
- human control points support authorized intervention without routine human relay.
- existing Claim/Dispatch/Human Decision owners remain canonical; no second lifecycle is introduced.
- focused positive and negative tests pass on exact candidate.
- concern Validation PASS and required Fresh Independent Review PASS bind the same candidate SHA.
- merge target is `version/v4.10.0`; Task/PR PASS is not Release PASS.
- Task Learning closeout is proportional and evidence-bound.
